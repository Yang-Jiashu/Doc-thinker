## 2. 来源复核：正确部分与实际缺口

### 共同正确的主方向

两版均建议 API 首版先采用 MemoryBank 式应用层外部记忆，暂缓 LongMem 的模型结构与训练改造。此判断有依据：S3 说明 MemoryBank 可兼容闭源模型；S2、S4 支持 LongMem 的冻结骨干、可训练侧网络和内部 attention key/value 路径。进一步对照 [MemoryBank v1](https://arxiv.org/abs/2305.10250v1) PDF 第 5 页 §3，以及 [LongMem v1](https://arxiv.org/abs/2306.07174v1) 第 4 页 §2.2、第 6 页 §3.1，这一主路线没有被原文推翻。

本轮未发现会改变这条主推荐的关键事实/引用错误，没有伪造实验数字，也没有把拟议两周产品试验写成已完成的论文试验。这个判断不表示全文所有语句都已由系统自动验证。

### 缺口 A：实验内容在原论文存在，但两版都没有交付

OFF 写“本次节选仅阐述……未报告具体基准测试结果”；AUTO 写“本次节选……未报告具体实验数字或基准成绩”。这是正确限定于当前节选的陈述，**不能误判成它们声称整篇 MemoryBank 没有实验**。

不过用户明确问了论文的实际验证，答案仍然缺了一半。MemoryBank PDF 第 8 页 §4.2 写明：15 名虚拟用户的 10 天对话，由 ChatGPT 按预设信息合成；人工编写 194 个中英记忆探针，检查检索、回答正确性与连贯性；第 9 页 Table 2 给出各版本结果。真实用户长期效果、两种记忆路线谁更优，都不能直接由这套合成测试推出。

这些页没有进入本轮 S1/S3，因而遗漏发生在最终证据输入阶段，不能靠多一个“验证门槛”提示补齐。本报告不要求模型凭外部知识猜论文结果，也不把诚实承认节选缺口视作幻觉；但面向产品团队的完整任务尚未完成。

LongMem 部分两版主要重复摘要的 ChapterBreak / ICL 改进陈述。原论文第 7–9 页 §3.2–3.3 才说明后缀识别、语言模型困惑度和 NLU / QA 上下文学习的评测对象、条件与指标；当前回答没有清楚解释它们与个人助手长期偏好效果的差别。缺少某个数值本身不是扣分原因，缺的是能解释验证范围的事实。

### 缺口 B：MemoryBank 的检索过程和更新限定不够清楚

两版的“怎样用历史”主要讲时间戳、摘要和用户画像，没有解释 MemoryBank 第 4 页 §2.2 的具体路径：把历史对话/事件与当前对话编码，用稠密向量检索索引找相关记忆。该节没有出现在最终材料里，因此本轮只完成了高层概述，没有给两位工程师足够明确的检索实现依据。

AUTO 的“按经过时间强化记忆”还需小修：第 4 页 §2.3 中时间流逝对应衰减，记忆被再次召回才增加强度并重置时间；作者把它明确限定为探索性的简化模型。不能把时间本身说成强化的原因，或把这种类人机制当成已经验证的通用最优记忆算法。此处是局部机制表达问题，不足以推翻 API 外部记忆的主路线。

### “不需要训练模型”的边界

AUTO 用此句解释为什么先做 MemoryBank。对本题的闭源 API 外部记忆原型，这是合理的工程判断，不应仅因当前 S1/S3 没有训练细节就判成错误。

但交接时应缩小为“不需要训练所调用的基础 LLM，也不需要复现 LongMem 的 SideNet 训练”。MemoryBank 第 5 页 §3 的 SiliconFriend 开源模型分支另有心理对话参数高效微调，而闭源分支并不做该步骤；论文也不保证两人两周能完成全部功能。不能把这句泛化成所有 MemoryBank/SiliconFriend 配置都没有训练环节。

两版引用的 LongMem 约 15ms/1k tokens、相当于骨干前向 55% 的检索开销可在 S4 和原 PDF 第 6 页找到，但应补“论文该实现配置下”，不能把它作为当前 API 产品的通用延迟预估。

## 3. 两周方案：有提醒，没有解决验收可执行性

OFF 至少提供了 5–10 位用户、无记忆对照、人工抽检的历史事实召回、1–5 分满意度和额外时延。它仍用“显著优于”“可接受范围”等未量化条件，未说明如何固定测试问题与历史、做配对比较、何时样本不足；需要补设计后才能执行。

AUTO 加入了“数据不足时不降低标准”，这是动态检查可见的正向表现。但它把实际通过条件写成“小流量”“可感知差异”，没有样本规模、可计数评价方式或预设阈值，甚至不如 OFF 的指标具体。声明“先写门槛”不等于已经替用户写出了门槛；给假设和建议挂 S 标签，也不能证明这些产品阈值或收益已被论文验证。

本题要求给两人团队一份可用于决策的短报告。两版都还需要人工补上实验材料、明确首版检索实现、固定试验输入及度量/停止条件，不能宣传成拿到即可无返工执行。

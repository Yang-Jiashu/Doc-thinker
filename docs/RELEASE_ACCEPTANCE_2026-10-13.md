# 持续研究任务的软件验收 · 2026-10-13

这是完整开发工作区的本机软件验收，不是公网发布、真实回答质量通过、长达数周的稳定性试验或自主 RSI 的证明。此前 V14 等模型评测 FAIL 保持不变。本轮没有新增供应商 API 调用；进程测试使用回环合成模型、合成账号和资料。

## 本轮交付

- 用户目标、约束、分析问题和无环依赖组成持久研究任务；分析复用已有 Harness、ResearchService、模型适配器和 RequestJournal。
- 修订号冲突检测、固定请求身份、调用次数批准、暂停/取消、重启读取和显式续做；结果未知停止对账，不自动补请求。
- 步骤独立资料范围，输入快照及下游闭包失效；资料清单更新不把所有无关完成步骤重新运行。
- 当前问题单独用于检索和任务路由；有界前步骤分析作为最终提示词数据，不作为原文证据，不静默漏掉依赖。
- 每步产物与报告版本保留引用，访问时检查当前来源；报告本地确定性汇集，不另发总结调用，不认证语义正确。
- 桌面/手机聊天页的长任务面板：计划编辑、显式选材料、调用次数确认、读取进度、失效版本提示、来源复核后复制/下载。只读操作不生成答案。

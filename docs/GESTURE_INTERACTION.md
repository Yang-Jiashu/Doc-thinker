# 图谱切换与手势交互

> 发布范围（2026-10-13）：以下为原开发工作区的新版交互设计与验收记录，**不是本次发布树的旧桌面入口操作说明**。本版按用户要求逐字节保留 GitHub 原桌面／图谱 Demo，不替换其手势实现；发布树的原图谱前端测试为 28 项。下文 81 项指未移入该入口的本地新版测试，不计入本版验收。手机端是单独增量入口，见 [发布范围](RELEASE_PUBLICATION_2026-10-13.md)。

标准视图与沉浸视图读取同一个会话的知识图谱，只改变呈现方式。标准视图显示重点节点并提供记忆管理，沉浸视图用于全量浏览；手势不是第三套图谱，也不会补边、删节点或调用 LLM。

## 使用方式

1. 在图谱顶部直接切换 **标准视图 / 沉浸视图**。当前会话、搜索词和选中节点通过 URL 传递。标准视图另外在本标签页保存布局与缩放位置；不把二维坐标直接搬成沉浸相机坐标。
2. 两边都有独立的 **手势设置**。打开设置不会申请摄像头权限；只有“开启摄像头”会申请。
3. **暂停**可恢复，**关闭**释放本应用的摄像头流。切换页面关闭摄像头；隐藏标签页暂停，回来后手动恢复。鼠标与触控始终保留，直接操作时优先接管并暂停手势，需要时在设置中恢复。
4. 惯用手、灵敏度、停留时长、防抖设置存于本机浏览器，两边共用。不会保存画面或“自动开摄像头”的偏好。

显式链接的会话不存在时不自动打开其他会话。返回标准视图的低度节点会在原有 200 个后端 / 50 个前端节点预算内优先保留；节点确实不存在则明确提示，不伪造替代。

## 两种模式

| 动作 | 精准模式（默认） | 演示模式 |
|---|---|---|
| 单独伸食指并稳定指向 | 停留后查看节点 | 查看节点 |
| 单手捏合 | 节点上抓取拖动；空白处平移 | 缩小 |
| 双手捏合并改变距离 | 按距离比例缩放 | 不用于精准缩放 |
| 张掌 | 不改变视图 | 水平移动旋转；标准二维视图对应平移。停稳后放大 |
| 握拳长按 | 复位一次，松开后才能再次触发 | 相同 |

不要在同一模式里让一个动作同时代表抓取和缩放。演示模式锁定已识别的动作，先松手再切换；默认精准模式不会因为普通横向指向就旋转整张图。

## 算法与实现

- **同一套核心**：`GestureStateMachine` 负责动作判定；`GestureController` 负责本地手部识别与生命周期；D3 标准图谱和沉浸渲染器仅提供 pick、pan、zoom、drag 等适配接口。旧的标准页独立手势实现已移除。
- **时间域平滑**：以经过的毫秒数控制 EWMA 平滑和连续缩放，不让不同设备帧率改变动作速度。停留计时遇到长时间断帧会重置，不把丢帧时间当作稳定手势。
- **迟滞和互斥**：捏合进入、松开使用不同阈值；单手抓取、双手缩放、复位分别占有当前操作状态。双手缩放按两手间距离的比例计算，不拼接多条生成式指令。
- **安全释放**：丢手、惯用手切换、重复身份或异常坐标跳变释放拖拽并重置基准，避免节点跳走。长握拳只能触发一次，必须松开才能再次触发。
- **异步隔离**：切会话后旧图谱、来源文本与后台状态响应不能覆盖新会话；取消摄像头启动时，迟到的流也会被停止。

识别在浏览器内执行，没有模型 API/token 开销，但仍消耗本机 CPU/GPU。MediaPipe 的 `detectForVideo` 是同步调用，当前以限频推理控制负载；尚未迁移至独立推理 Worker，低配设备需实测延迟。其 tracking confidence 是跟踪条件，不等于业务手势准确率。[MediaPipe 官方说明](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/web_js)

暂停 track 与停止 track 是不同操作；这里只控制本应用持有的流，不承诺关闭其他应用的摄像头。[Media Capture 规范](https://www.w3.org/TR/mediacapture-streams/) 移动端不能只依赖 `beforeunload`，因此处理隐藏、pagehide 和返回恢复。[Chrome 页面生命周期说明](https://developer.chrome.com/docs/web-platform/page-lifecycle-api)

## 验证边界

2026-10-11 补齐输入接管：标准 D3 与沉浸图的滚轮、图谱工具栏、有效快捷键和窗口失焦都会暂停摄像头手势；不会自动恢复，也不会抢输入框、中文输入法或浏览器组合快捷键。沉浸图忽略双指操作中的第三个触点，指针捕获丢失和切页会释放临时拖拽。摄像头超过 300 ms 没有新帧时重置临时手势状态，不清除选中节点、不复位视图、不修改永久知识。

本次图谱前端 **81 项测试通过**，包含输入控制器、冻结帧释放与运行真实标准视图适配器的 VM 测试；TypeScript 检查通过。这里的断帧阈值是安全停止策略，不是已经测得的摄像头延迟或识别准确率。

使用离线 landmark/时间序列与模拟媒体流测试动作互斥、拖拽释放、帧率一致性、启动取消和权限失败；使用本地模拟图谱验证双向导航、特殊字符节点、会话切换和移动布局。没有替用户授权摄像头，也没有把这些测试称作真实手势识别准确率测评。

面向客户前还应使用实际摄像头，在左右手、不同光照、遮挡、背景、移动设备和长时间使用下记录误触率、选择耗时与推理帧延迟。识别差时用户可以随时退回鼠标操作。

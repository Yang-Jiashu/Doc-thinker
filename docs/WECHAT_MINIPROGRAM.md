当前交付是 **uni-app 编译出的微信开发者工具工程**，不提供安装包。默认构建使用 `touristappid` 游客标识，也可通过环境变量配置自己有权限的 AppID。工程构建成功不等于已注册账号、已生成手机预览或已发布体验版。

2026-09-22：用户确认只有个人主体，并同意先推进[邀请制 HTTPS 网页内测](INVITE_WEB_BETA.md)。该路径是在微信浏览器打开网页，**不是小程序公开上线，也不能被小程序搜索到**。以下正式小程序计划暂作后续参考，不继续默认购买域名或申请企业资质。

2026-09-19 已在 macOS ARM64 的微信开发者工具 Stable 2.02.2608070 中，使用用户提供的 AppID 完成本地导入，并在基础库 3.17.3 的模拟器检查助手、资料、记忆、图谱、设置页面；演示提问返回明确标注的模拟回答，图谱节点可展开邻接关系与原文。随后工具成功生成开发版预览二维码，首次显示代码包 220 KB；编译提示仅说明 README 与开发者私有配置未上传。此记录不代表 Android / iOS 已扫码运行、真实模型或多人体验版验收通过；临时预览码会过期，需在工具中重新生成。

## 发布目标与当前阻塞

2026-09-20 用户确认此前使用的是**测试号**，最终目标是**微信按名称可搜索的正式小程序，业务仅向受邀用户开放**。不是继续生成临时预览码，也不是让体验版参与公开搜索。正式发布须经过平台审核；允许搜索不保证立即收录或排名。[微信发布流程](https://developers.weixin.qq.com/miniprogram/dev/framework/quickstart/release.html)

当前未注册或验证可用于本项目的正式账号，未完成正式上传、审核或发布。已有代码可以复用，但不能只替换 AppID 就宣称完成上线：

| 发布前置项 | 当前状态 / 下一步 |
| --- | --- |
| 运营主体与 AI 服务类目 | 等待用户确认可合法使用的主体；不要先默认注册个人账号。 |
| 正式账号和开发权限 | 主体确认后完成注册/验证，再配置对应 AppID；格式检查不验证正式资格。 |
| AI 资质与模型授权 | 按真实供应商取得所需材料，确认套餐允许向受邀用户提供服务；不得借用无关厂商资质。 |
| 小程序备案、隐私与审核材料 | 用户确认真实主体、联系方式及数据处理方式；不代填虚构信息。 |
| 微信登录、邀请名单与数据隔离 | 尚未实现；当前私人访问码不适合多人共用，需服务端逐用户、逐对象授权和配额。 |
| HTTPS 和真实业务验收 | 尚未部署；默认演示包不作为可提审完成品，资料、记忆与语音按实际完成情况开放。 |

腾讯云开发官方指引目前说明「深度合成—AI 问答」仅向非个人主体开放，个人小程序不能申请；具体主体资格须按平台实际类目要求确认，不能据此保证任何个体工商户都能获批。使用第三方技术还需要对应算法资质及合作材料，API key 本身不是资质证明。[AI 类目与资质说明](https://docs.cloudbase.net/ai/release/algorithm-filing)

邀请制是如实披露的业务访问限制，不是绕过审核的方法。提审时需说明邀请流程并给审核人员可完整体验的测试权限；不隐藏功能、不审核后偷开功能。公开入口仅呈现产品介绍和申请入口，不展示私人会话、资料、图谱或记忆。[微信审核规则](https://developers.weixin.qq.com/miniprogram/product/reject.html)

正式注册入口为[微信公众平台](https://mp.weixin.qq.com/)的「立即注册 → 小程序」。主体、实名、协议和必要的支付由用户本人确认；只向开发者提供需要的 AppID，不在聊天或客户端中提供 AppSecret。注册前先确认类目与主体，暂不购买域名、服务器或代办服务。[腾讯官方注册步骤](https://cloud.tencent.com/document/product/1598/80508)

## 1. 现在可以做什么

在微信开发者工具的模拟器中导入工程，使用「演示模式」查看问答、资料、图谱、记忆、会话切换和设置流程。演示数据与回答是本地样例；演示录音和转写是模拟交互，不采集真实声音，不调用模型。已有本地构建与离线测试不等于开发者工具、Android 微信或 iOS 微信实机验收。

五个入口是**助手、资料、记忆、图谱、设置**。记忆页只读查看当前会话已保存的摘要和对应提问，明确标为“待核对”，每页最多 20 条；不调用 LLM 生成新记忆，也不承诺已完成跨会话偏好学习或完整删除。微信端选择聊天文件/相册图片前先检查平台隐私授权，上传前再次确认目标服务；切页、拒绝或修改服务配置后不会继续发起该次上传。语音先成为可编辑草稿，再由用户发送。

`touristappid` 是 DCloud 官方编译器在 AppID 缺省时采用的游客标识，不是伪造的正式 AppID，也不等于微信平台发放的测试账号。官方测试账号可能需要用户登录并申请；本工程不会代办。游客模式的具体接口限制以当前开发者工具提示为准；**本交付不承诺游客模式能微信扫码预览、真机调试、上传或生成体验版**。这些留到取得自己有权限的 AppID 后验收。[DCloud 官方编译器源码](https://github.com/dcloudio/uni-app/blob/next/packages/uni-cli-shared/src/json/mp/project.ts)

## 2. 构建并导入

在仓库根目录执行（已安装依赖可跳过 `npm ci`）：

```sh
cd clients/mobile
npm ci
npm run build:mp-weixin
```

构建成功后导入 **`clients/mobile/dist/build/mp-weixin`**，即同时含 `app.json` 和 `project.config.json` 的目录。不要导入 `src`、整个仓库或旧的原生样例 `miniprogram/`。

1. 用户自行打开已安装的微信开发者工具，选择导入项目；使用游客入口/无 AppID 路径（名称随工具版本变化）。无需向本项目提供账号密码。
2. 目录选择上述产物，工程配置中的 AppID 为 `touristappid`。不要求填写 AppSecret。
3. 默认保持「演示模式」，点击编译，检查各个标签页；图谱使用实体列表、邻接关系和来源查看，不是可缩放的全图画布，也不包含桌面摄像头手势识别。
4. 若工具要求账号登录或禁止某项游客功能，不要填写别人 AppID，不把限制当作真实业务请求成功；先使用可用的模拟器功能。

编译产物已带完整页面 JS/WXML/WXSS，无需在微信开发者工具再执行「构建 npm」。本仓库 `dist/` 不提交到 Git；编译完成后的 AppID 和开发者工具私有设置只留在本地输出目录。DCloud 支持 CLI 项目在 `src/project.config.json` 自定义小程序工程配置；模板只含游客标识。[DCloud 配置文档](https://zh.uniapp.dcloud.io/collocation/manifest.html#自定义小程序项目配置)、[微信官方示例工程配置](https://github.com/wechat-miniprogram/miniprogram-demo/blob/master/project.config.json)

## 3. 拿到自己的 AppID 后

仅在你有该小程序开发权限时，通过构建环境变量指定 **真实微信 AppID**。它必须符合 `wx` 加 16 位小写十六进制字符；以下是格式占位，不可原样执行：

```sh
DOCTHINKER_WEIXIN_APPID='<你的真实微信AppID>' npm run build:mp-weixin
```

Windows PowerShell 可先设置 `$env:DOCTHINKER_WEIXIN_APPID` 再构建。变量未设置或为空时回到游客模式；格式错误会在调用编译器之前失败。脚本只把校验后的身份写入 `dist/build/mp-weixin/project.config.json`，不改跟踪的 `src/manifest.json` / `src/project.config.json`。**任何客户端构建均不需要 AppSecret、微信登录密钥或模型 API key。** 未来如接微信登录，AppSecret 只能由受保护的服务端管理。

这一步只是身份配置，不会登录、上传、扫码或发布。脚本只校验 AppID 字符串格式，不验证账号类型、归属、开发权限或上传资格；构建报告的 `configured-appid` 不代表已获得体验版权限。

| 路径 | 含义与前提 |
|---|---|
| 游客模拟器 | 无 AppID 时的本地样例交互，无真实模型能力承诺。 |
| 官方测试号 / sandbox | 与游客标识、正式小程序账号分开；预览、调试、上传及成员能力，以该测试号后台和开发者工具实际提供的权限为准。持有 AppID 不等于可以发布体验版。 |
| 开发版真机预览/调试 | 自己有权限的 AppID、开发者工具登录及平台允许的开发者/测试人员；由用户主动扫码。在 Android 与 iOS 微信分别检查权限、布局和网络。 |
| 体验版 | 仅适用于已确认支持相应上传与版本管理能力的账号。有权限的开发者主动上传，管理员按平台流程设置体验版本与体验成员；不等于公开发布。 |
| 正式版 | 平台要求的账号资质、服务类目、隐私声明、审核和发布；本交付未执行或保证获批。 |

## 4. 私人服务和合法域名

2026-09-20 用户确认能扫码进入预览，并选择保留加密连接。手机到电脑的真实 HTTPS 接入尚未完成；没有自有域名时，先确认正式账号的主体与 AI 类目资格，再办理所需域名/云资源。测试号域名能力不再作为正式发布的替代路径，也不直接公开电脑。具体方案与验收边界见[私人加密接入准备](WECHAT_PRIVATE_DEPLOYMENT.md)。

没有后端和域名也能使用本地演示。切到「私人服务」才会访问你配置的 DocThinker 移动 API；接口失败会报错，不退回模拟回答假装成功。私人服务凭据不是微信 AppSecret，也不是模型 key；当前移动入口是受访问码保护的私人工作台，不应向多个不互信用户共享同一个访问码。

正式/体验/真机联网验收前，用户需部署可达、证书有效的 **HTTPS 服务域名**，并在自己小程序后台配置合法域名。手机的 `localhost` 是手机自身，不是这台开发电脑；开发者工具本机网络通了也不代表手机能访问。平台关于备案、端口、证书与账号主体等要求以后台和[微信网络说明](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)为准。

| 合法域名分类 | 本项目用途 |
|---|---|
| `request` | 会话、资料/图谱读取、提问、语音能力查询；当前微信端 TTS 也是 `request` 获取音频二进制。 |
| `uploadFile` | 用户主动上传的资料，以及真实录音提交语音转写接口。 |
| `downloadFile` | 如后续引入 `wx.downloadFile` 或直接远程文件下载，须单独配置实际下载域名；当前 TTS 不调用 `downloadFile`，不因名称是“音频下载”就配置错分类。 |

工程强制 `setting.urlCheck: true`，**不要勾选「不校验合法域名、TLS 版本以及 HTTPS 证书」作为交付方案**。开发者工具的 `project.private.config.json` / 本地设置可能覆盖共享配置，验收时也要确认域名校验仍开启。游客模式下若合法域名无法配置，私人网络功能就保持待验收，继续使用演示模式。

后端语音另需显式启用并配置 ASR/TTS；它不自动继承已有 LLM key，详见仓库 `docs/VOICE_MODELS.md`。客户端不直接调用模型厂商，模型凭据只留服务端。

## 5. 隐私与语音验收

真实录音、选择照片/资料是用户主动动作。`scope.record` 只用于运行时录音授权；不要将它写入 `app.json` 的 `permission` 用途描述，开发者工具会判为无效配置。运行时录音授权和应用内提示，**也不等于已完成微信《小程序用户隐私保护指引》配置和平台授权**。运营者需要在自己的小程序后台如实声明录音、照片/文件、转写文本等实际处理的信息、用途、保存/删除方式、联系方式及上游处理方，并按当前平台要求完成隐私授权后再验收受保护接口。[微信隐私授权文档](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/PrivacyAuthorize.html)

本项目的语音流程是「用户录音 → 送私人服务转文字 → 用户确认发送 → 可手动朗读回答」，不是实时全双工电话，不做声纹识别或声音克隆。即使 ASR/TTS 部署在私有服务器，也不代表全程在手机离线处理。授权拒绝、系统中断、切会话/隐藏页面、取消录音、取消朗读都应停止对应操作；这些已设离线生命周期测试，仍须在两个手机平台真测。**当前没有做真实麦克风、真实语音模型、真机或微信体验版验收。**

`sitemap.json` 默认禁止页面被搜索索引，只是页面内容的搜索策略，不是资料访问控制或保密保证，也不等于账号级「允许被搜索」设置。不要为了小程序名称可搜索就无条件开放所有私人页面索引。

## 6. 包体积门禁与交付检查

`build:mp-weixin` 完成后会：

- 从已编译 JS/JSON/WXML/WXSS 收集品牌资源的完整字面路径，只保留实际引用图像；方案对比 SVG、App 全套尺寸和 PWA 大图标不会无条件复制进交付包。新增动态拼接品牌路径或缺失资源会报错，不会静默删坏界面。
- 对导入目录的**所有文件未压缩字节数**执行 **2,000,000 字节**的本项目保守上限，包含文档/配置的统计比实际上传内容更保守。它不是微信开发者工具上传后的精确包大小，也不是对所有平台分包额度的承诺。
- 当前无分包，新增分包会先使门禁失败，需另行实现逐包计量，不能借分包字段绕过检查。平台最终大小结果还须由开发者工具核验。[微信分包文档](https://developers.weixin.qq.com/miniprogram/dev/framework/subpackages/basic.html)
- 在导入目录外输出 `dist/build/mp-weixin-size-report.json`：文件数、总大小、最大文件、保留/剔除的品牌路径，不含 AppID 或密钥。只有构建退出码为 0 才算通过；失败产物不作为可交付包。

可重复离线验证：

```sh
node --test tests/weixin-build.test.js
```

验收进度：本机开发者工具导入和五个页面显示已验证，用户确认测试号扫码能进入。下一阶段先满足本页「发布目标与当前阻塞」中的账号与主体前提，再完成正式 AppID 下的真机网络、逐用户授权、数据隔离、真实问答及已开放功能验收；最后才是提审、发布和搜索入口核验。未完成的步骤不要标记成功。参考核查日期：2026-09-20；平台账号能力与类目资格最终以当前开发者工具/后台实况为准。

# 2026-10-20 工程快照

本次同步的是已实现的软件能力，不是“完整 personal agent 已商用上线”的声明。项目定位仍是私人助手，不限于论文。原有 Logo、品牌素材、Demo 和 Harness / Insight Schema 框架保留。

## 已实现

- 长期项目保存总目标和验收条件，可追加阶段；每阶段复用原有 1–6 问任务执行器，不新增第二套执行框架。
- 计划可增删步骤、调整依赖，先预览影响再确认；保留不受影响的完成分支，变更不自动重跑或增加付费调用。
- 跨阶段交接绑定明确选择的报告和步骤版本；只传有界内容，不回放全项目历史。
- 派生回答绑定父任务、步骤、原始资料及确认记忆。依据或父步骤变化后，报告、聊天中的派生内容和确认记忆按引用链失效。
- 修复长历史批量读取的 128 项误判，以及真实邀请 worker 与直接数据适配器的任务库存放差异。
- 网页聊天中提供长期项目、阶段验收和关联任务计划入口。

## 软件验证

- Python 回归：6,372 项通过，另有 13 个 subtest 通过、7 项可选浏览器／本地模型依赖测试跳过。
- 客户端：897 项通过；网页、小程序游客资源和 App 资源构建通过，不代表已发布或签名安装。
- 原生接口：30 阶段、3 次重启；150 阶段祖先检查；160 步回答依赖的批量读取与来源撤回。
- 真实网关与两个独立 worker 子进程：重启续做、授权配额幂等、定向重算、报告版本、来源撤回及租户隔离通过。模型为本地替身，共 5 次调用、零厂商调用。
- 30 阶段本地遍历基准：任务库连接 59 → 1，中位耗时 18.57 → 2.79 ms。这里只比较遍历开销，不是模型端到端提速。

## 尚未实现或未通过的核心边界

个人事件模块已支持来源、关系、版本与撤回，但尚未把事件结构完整接入聊天和长期任务的检索、模型输入及任务版本约束。现有文档图扩展用于寻找相关原文，不是个人事件因果引擎。

仍缺任务级语义证据义务、支持／反证／未知状态和缺口驱动的补查—判断—重规划闭环。可溯源、可恢复及引用正确，不等于关键证据找齐、因果解释正确或用户目标达成。Insight Schema 的结构检查不能替代这些能力。

本轮没有新增真实 Step 5 或其他付费模型的质量／token／延迟对比，不改变历史失败结果。文档目录和存储仍有容量上限；没有自动获批的外部行动、跨周无人值守付费工作或完整 RSI。公开 HTTPS、真机体验、签名安装包、实际账单与生产容量仍需独立验收。

# 移动端开发预览：H5、微信小程序和 App

## 当前定位

这一轮是 **uni-app Vue 3 共用页面 + 私人 DocThinker 实例接口**，用于开发预览和受控联调，不是面向客户发布的多租户产品。

- 没有微信 AppID、服务器和域名时，可以先在电脑浏览器检查页面、布局和交互，并编译微信小程序/App 资源。
- 编译成功不等于已在微信真机运行，也不等于已生成可安装的 APK/IPA、完成签名或通过应用商店审核。
- 没有连接后端、文档未解析或语音服务未配置时，应显示真实状态；不能把固定示例、录音文件或构建产物当成模型回答、识别结果或已发布应用。
- 微信登录、用户归属授权、计费配额、可靠任务队列和正式发布资质不属于本轮完成项。

移动工程位于 `clients/mobile`，共用助手、资料、记忆、图谱和设置五个页面。默认演示模式使用带有“模拟/示例”标记的固定资料、记忆、回答和语音转写，不连接真实模型、不申请麦克风；它用于走通交互，不代表算法效果。演示会话/消息保存在运行内存，刷新可能重置。只有主动配置并切换至私人实例，才会使用真实后端和后端持久化。

Web、微信小程序和 App 可复用业务页面，但网络、文件选择、录音及发布流程有平台差异；不能直接把桌面 D3/Three.js 图谱和摄像头交互原封不动搬入小程序。

## 本地运行与构建

从仓库根目录进入移动工程。安装依赖可能访问 npm；这与调用文档模型/语音模型是两件事。

```sh
cd clients/mobile
npm ci --ignore-scripts
npm test
npm run build:h5
npm run preview:h5
```

预览命令需要 Python 3，仅把编译产物暴露在本机回环地址。锁文件用于可复现安装。不要单独升级某一个 `@dcloudio/*` 包：uni-app 编译器包需要保持版本匹配。

### 浏览器 H5

本地静态预览位于 `http://127.0.0.1:5175`，与热更新开发端口 5174 分开。没有微信 AppID 不妨碍 H5 演示；真实问答仍需要你自己的 DocThinker 后端和已配置模型。`npm run build:h5` 生成含 PWA 安装配置的 H5 静态资源，仍需由 HTTP 服务承载，不能以双击文件代替部署验证。修改源码后重新构建；安装了离线界面的旧窗口需先保留草稿再关闭重开，以使用新版。详见[安卓与苹果安装方式](MOBILE_INSTALLATION.md)。

**依赖安全未达到发布标准。** 2026-09-19 对当前锁文件运行 `npm audit`，仍报告 30 项依赖告警（17 low、10 moderate、3 high，含传递依赖重复计数）。已通过 overrides 更新国际化解析、压缩包、图片解析、PostCSS 和 WebSocket 相关依赖，并复测三端编译；仍有官方工具链锁定的 Vite、esbuild、Babel 及 Express/Jimp 依赖告警。不能把这些全部视为“仅开发依赖所以无风险”，也不能以强制大版本升级代替兼容验证。正式发布前需升级匹配的工具链、重新审计并做产物与真机验收。

`npm run dev:h5` 保留给开发人员，但它会启动当前有已知告警的 Vite 开发服务器，**不作为默认体验入口，不应公开或处理真实资料/凭据**。本轮预览使用静态产物服务器，并未启动它；静态预览不代表消除了构建链的全部风险。

不要把前端开发服务器当作后端。电脑浏览器中的 `127.0.0.1` 指电脑；手机中的 `127.0.0.1` 指手机自身。跨设备联调需要正确的网络地址及访问控制，不能通过随意公开整个后端来解决连接问题。

### 微信开发者工具

1. 在 `clients/mobile` 运行 `npm run build:mp-weixin`。
2. 在微信开发者工具中导入 **`clients/mobile/dist/build/mp-weixin`**，而不是直接导入 Vue 源码。
3. 没有自己的 AppID 时，构建输出明确使用 `touristappid`，仅用于游客模拟器工程；不借用他人 AppID，不承诺扫码、真机预览、上传审核都能使用。
4. 有自己的 AppID 后，通过 `DOCTHINKER_WEIXIN_APPID` 环境变量构建，仅写入本地输出，再分别验证开发者工具和真实手机。完整步骤见[微信小程序测试版说明](WECHAT_MINIPROGRAM.md)。

uni-app 官方说明了平台构建命令及 CLI 项目的 `dist/dev`、`dist/build` 产物目录；正式发布微信小程序仍需申请 AppID、上传并通过微信审核。[CLI 快速上手](https://uniapp.dcloud.io/quickstart-cli.html)、[发布为小程序](https://uniapp.dcloud.net.cn/quickstart)

测试工程保持域名校验开启，不以关闭校验作为验收方案。联网验收前必须按微信当前规则配置实际请求/上传/下载用途的合法域名、HTTPS 证书和相应权限；请以[微信网络能力说明](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)为准。

### HBuilderX 与 Android/iOS

1. 用 HBuilderX 打开移动工程，安装匹配的 uni-app 编译环境。
2. Android 使用连接的测试手机或模拟器；真机需允许 USB 调试。通过“运行到手机或模拟器”选择设备。
3. iOS 真机测试涉及自己的签名证书/自定义基座；Mac 上也可根据环境使用 iOS 模拟器。标准调试基座不等于可对外分发的正式应用。[官方真机运行说明](https://zh.uniapp.dcloud.io/tutorial/run/run-app.html)
4. 本项目 `npm run build:app` 使用 Vue 3 的 `app` 平台参数。CLI 生成 App 资源并不会自动产出签名 APK/IPA；云打包需要 HBuilderX，且需要 DCloud 账号。正式签名、包名、权限、证书和商店提交另行完成。[官方 CLI 能力边界](https://uniapp.dcloud.io/worktile/CLI.html)、[云打包说明](https://uniapp.dcloud.io/dev/app/cloud-build.html)

微信 AppID、DCloud AppID、Android 包名/签名和 Apple Bundle ID/签名是不同配置，不能互相替代。不把私有访问令牌、模型 API Key、微信 AppSecret 或签名私钥写入前端源码、构建产物或提交到仓库。

## 私人实例的安全边界

移动接口使用独立的 `docthinker.server.mobile_app` 入口，只挂载 `/api/v1/mobile` 白名单接口，不挂载原桌面/管理 API。它使用独立的安全启动配置：必须指定绝对 `DOCTHINKER_MOBILE_DATA_DIR`，且不能与桌面存储重叠。不迁移/搬动旧资料、不自动探测模型、不启动上传后聚类或额外自学习。默认模式的长期记忆使用该目录内的独立 SQLite，只读召回已有会话记忆，不自动写新长期记忆；聊天历史仍会保存。

没有显式配置 embedding 地址、模型与专用凭据时，只准备主聊天客户端，不创建 GraphCore/解析器，也不自动采用其他厂商的默认 embedding。此时支持主动普通聊天和历史上下文，资料上传与文档检索保持不可用。主模型配置就绪不等于已验证一次真实模型回答；能力接口分别报告 `chat_ready`、`document_rag`、`uploads`、`automatic_learning` 和 `memory_write_enabled`。桌面入口的原有默认流程不因手机安全配置而改变。

**新有界研究模式是另一个显式配置。** 在下面启动命令之前另设 `export DOCTHINKER_RESEARCH_ENABLED=true`，即可启用本地 PDF/TXT/MD 解析、项目内检索/原文引用和用户手动确认的可修订记忆；无需 embedding，不创建 GraphCore，也没有自动偏好学习或夜间补边。不能同时启用旧 embedding RAG 配置，混合配置会拒绝启动。上传/记忆管理不调用模型，问答最多一次调用；断线后按原请求编号查询，未知结果不自动重发。项目隔离不改变下文的共享令牌权限边界。实际预算与缺口见 [核心架构](ARCHITECTURE.md#有界研究核心2026-10-10)，多用户邀请部署见 [显式研究开关](../deploy/invite/README.md#开启研究核心)。

启动前由管理员在自己的进程环境注入 **至少 32 个字符的随机** `DOCTHINKER_MOBILE_ACCESS_TOKEN`；不要使用固定示例口令、把令牌提交到仓库或显示在演示屏幕。下列命令不包含令牌：

```sh
export DOCTHINKER_MOBILE_ENABLED=true
export DOCTHINKER_MOBILE_DATA_DIR="$HOME/DocThinker-Phone-Private"
export DOCTHINKER_MOBILE_CORS_ORIGINS=http://127.0.0.1:5175
python -m uvicorn docthinker.server.mobile_app:create_mobile_app --factory --host 127.0.0.1 --port 8001
```

独立入口启动前会检查启用状态、令牌长度和数据目录；不满足时直接拒绝启动，不先创建数据库或模型客户端。服务运行后的路由也持续校验开关与令牌：关闭时返回 404，缺少足够长度的服务端令牌返回 503，访问令牌无效返回 401。H5 跨域必须显式设置允许的前端 origin，不能填 `*`；小程序/App 不依赖浏览器 CORS，但仍必须通过同样的令牌校验。

移动端设置页填写 **API origin**（例如本机 `http://127.0.0.1:8001`），不附加 `/api/v1/mobile`；客户端会追加路径，并使用 `Authorization: Bearer …`。令牌是私人实例的访问凭据，不是模型 API Key，也不是微信登录凭据。

保存私人配置后可手动点击“检查连接（不调用模型）”：只请求能力接口，八秒超时、不重试、不读取会话资料。改配置或离开页面会取消检查，过时响应不能显示成功。通过仅代表服务协议和鉴权检查成功，不代表模型、语音或多用户隔离验收。当前无域名的安全接入准备见[加密部署方案](WECHAT_PRIVATE_DEPLOYMENT.md)。

**共享令牌不是多用户权限系统。** 获得令牌的人应视为该私人实例的可信使用者；不能声称不同客户仅能看到自己的会话。现有会话目录、图谱 workspace 和缓存隔离解决的是存储串用，不是访问者归属授权。

**不要用原后端的 8000 端口替代独立入口，也不要直接公开原桌面服务。** 移动入口的校验不会自动保护另一个进程里的 `/api/v1/sessions`、`/query`、`/ingest`、`/settings`。手机跨设备联调需受控网络/网关；不要把监听地址简单改成 `0.0.0.0` 后开放整台服务。远程连接使用 HTTPS，并先从未授权设备验证拒绝行为。CORS 不是身份鉴权。

客户端将访问令牌只保留在本次运行的内存，不写本地持久存储；刷新/重启后需重新填写。切换后端地址时清除未重新提供的旧令牌，避免把实例 A 的凭据发送给实例 B。不能把令牌放进 URL、二维码或日志；使用完共享测试设备后清理其连接配置。网络超时或服务器错误不应自动切换为另一台服务器或伪造的成功结果。

当前移动问答使用非流式 `/query`，同进程最多同时处理两个问题、同会话最多一个；客户端不自动重试。旧 embedding RAG 的资料格式允许 PDF/TXT/MD/DOCX/PNG/JPG/JPEG，单文件上限 20 MiB；有界研究模式仅接受 PDF/TXT/MD、10 MiB/文件、20 份/项目，不开放图谱。旧图谱只请求最多 200 个节点的摘要，实体原文最多三段；这不是全库下载或完整因果链展示。上述限制是开发入口的本地限制，不是跨进程用户配额。

## 语音：录音、转写、问答和朗读是四个步骤

正确的用户路径是：主动开始录音 → 停止 → 查看转写文本 → 确认后提问。朗读回答是另一个可选动作，不能默认等同于持续监听或实时双向语音通话。

- 首次录音需要明确的麦克风授权；拒绝权限后，文字输入仍应可用。切页、退出或中断时应释放录音，不在后台悄悄重新开始。
- uni-app 的 `uni.getRecorderManager()` 支持 App/微信小程序，但官方兼容表不支持 H5。本项目 H5 单独使用浏览器 `MediaRecorder`；不支持相应 API/编码或非安全上下文时提示改用文字。不能仅因同一页面能编译就宣称所有浏览器都能录音。[录音管理器兼容表](https://uniapp.dcloud.net.cn/api/media/record-manager.html)
- 本地录音不等于离线语音识别。若用户主动使用真实语音后端，音频或待朗读文字可能交给管理员配置的服务商处理，并产生费用；界面应在上传前说明，不把音频默认写入知识图谱。
- 本轮离线测试不代表完成了真实麦克风、语音服务商、手机后台切换或蓝牙耳机验证。长音频、方言、噪声、格式兼容和设备中断需要单独实测。

资料选择也有平台差异：H5/微信可使用各自文件选择能力；当前 App 页面只提供图片资料入口，系统 PDF/DOCX 文件选择仍需原生能力适配，不应显示为已完成的全端功能。

真实语音默认关闭，由管理员单独配置下列环境变量，不继承问答模型的密钥或厂商：

| 配置 | 用途 |
| --- | --- |
| `DOCTHINKER_VOICE_ENABLED` | 显式启用真实语音服务 |
| `VOICE_ASR_BASE_URL`、`VOICE_ASR_MODEL`、`VOICE_ASR_KEY` | 转写服务的 OpenAI-compatible API base、模型和凭据 |
| `VOICE_TTS_BASE_URL`、`VOICE_TTS_MODEL`、`VOICE_TTS_KEY`、`VOICE_TTS_VOICE` | 朗读服务及音色 |

API base 不要重复包含 `/audio/transcriptions` 或 `/audio/speech`；填错配置时能力接口显示不可用，不会自动借用其他厂商凭据。公开网络的语音服务使用 HTTPS；凭据只放后端，不能填到移动端“私人测试访问码”中。

客户端录音设置为最多 60 秒；后端另有 10 MiB 音频上限，单次朗读最多 1500 个字符。容器格式检查不等于完整音频解码验证。实际可用格式、转写和音色支持还取决于服务商；本轮没有进行付费调用或麦克风实测。

## 开发验收清单

- [ ] 未开启移动服务时，所有移动路由拒绝访问；已开启但没有正确令牌也拒绝。
- [ ] 会话、问答、上传、图谱、证据和语音均使用相同访问校验，不存在单个路由遗漏。
- [ ] 移动路由不透传任意路径/URL，不提供模型配置、磁盘路径或管理接口代理。
- [ ] 会话不存在时明确报错；不自动选择其他会话。快速切换会话后，旧响应不能覆盖新页面。
- [ ] 后端地址变化后清除旧令牌；发布包、错误信息、访问日志和 URL 不包含敏感凭据。
- [ ] 上传明确区分“已接收”“解析中”“完成”“失败”；超限/不支持格式拒绝，重试不伪报成功。
- [ ] 语音未配置时可见且明确禁用；拒绝权限/中断/退出后不会继续采集，文字路径可用。
- [ ] H5、微信编译、App 资源编译分别通过；另行记录真实微信工具/设备、Android、iOS 的验证结果。
- [ ] 新接口与语音测试使用 mock 服务、临时存储，不读取实际 `.env`，不触发真实模型或麦克风。

离线合同测试可从仓库根目录运行：

```sh
python -m pytest tests/test_mobile_contract_unit.py tests/test_voice_api_unit.py -q
```

这些测试检查路由白名单、访问校验、请求限制、参数传递和错误脱敏；不能替代手机端权限、录音编码、后台切换和发布验收。

验证记录（2026-09-20，私人接入准备）：移动端 Node 测试 **221 项通过**，全仓 Python 测试 **723 项通过、1 项跳过**（排除手工调试脚本 `tests/debug_db.py`，另有 9 个 subtests）；新增 15 项手机安全启动测试。H5、微信小程序和 App 资源三项构建通过。已在微信开发者工具检查五个页面和演示发送/图谱详情，用户确认手机能扫码进入。此前浏览器检查了 390 × 844、320 × 740 布局。微信包启用 2,000,000 字节未压缩主包门禁，实际统计见 `clients/mobile/dist/build/mp-weixin-size-report.json`。

另用本机当前模型配置、临时独立目录与内存随机令牌完成一次真实应用工厂启动检查：禁止出站网络时启动成功；未认证返回 401，管理端点返回 404，能力接口返回 200，手机目录没有旧会话，出站连接尝试为零。主聊天配置就绪，RAG、上传和自动长期记忆写入明确不可用。检查结束即关闭临时实例，未开放网络端口或保存访问码。没有因此宣称完成手机 HTTPS、真实语音或多人体验版验收。

## 对客户开放前仍需完成

1. **真实身份与逐对象授权**：微信登录由服务端换取身份，建立用户/租户；会话、文件、chunk、图谱节点、语音任务和删除操作都检查 owner/ACL，不能只信客户端 `session_id`。
2. **管理面隔离**：独立管理员鉴权，网关拒绝内部端点；HTTPS、明确 CORS 来源、令牌吊销/过期和安全日志。
3. **资源与费用限制**：按用户限制文件数量/大小/类型、录音长度、并发、问答频率和模型额度；共享访问令牌不能承担客户计费。
4. **可靠任务和消息**：持久任务 ID、队列、失败重试/取消/重启恢复；消息幂等 ID、生成状态、断线恢复、分页历史及删除/导出流程。当前进程内后台任务不能代替可靠队列。
5. **隐私与发布准备**：明确文档/录音的用途、服务商、留存与删除策略；完成小程序/App 账号、域名证书、应用签名、隐私声明、所需备案与平台审核。具体材料以各平台当时要求为准。
6. **依赖与产物安全复验**：解决上述审计告警，验证编译链升级兼容性、最终包内容及 Android/iOS/微信真机行为。

检查完成前，交付名称应是“开发预览/私人实例联调版”，不是“客户可用正式小程序”或“已发布 App”。
